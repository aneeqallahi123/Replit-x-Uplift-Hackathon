# Dastak Voice Agent — Real Flow Fix (Complete Rewrite)

## Critical problem with the current implementation

The agent is triggering #appFormOffcanvas — a Bootstrap offcanvas 
sidebar — when the user clicks the "Renewal of Regular License" card.

THIS IS WRONG.

That offcanvas is NOT what happens in the real website flow. Look at 
what actually happens when a real user clicks that card:

1. The card gets highlighted green (selected state)
2. A "Choose How You Want to Apply" section APPEARS ON THE SAME PAGE
   below the service cards — showing Self Service vs Doorstep Service
   options, a Required Documents table, Fee information, and an 
   Apply button
3. The user selects "Self Service"  
4. The user clicks "Apply"
5. The browser NAVIGATES to apply.html — a completely separate page
6. apply.html contains the actual form with fields:
   CNIC, License No., License Issuance Date, Renewal Duration,
   Is old License in Possession, a math captcha answer, and Submit

The agent must follow THIS flow. Not the offcanvas. The offcanvas 
(#appFormOffcanvas) should never be opened by the agent at all.

## Page detection logic — single voice-agent.js handles all 3 pages

const path = window.location.pathname + window.location.search;

if (path.includes('index') || path === '/' || path.endsWith('/')) {
  // HOME PAGE
  document.getElementById('mic-btn')
    .addEventListener('click', handleMicClick);
  function handleMicClick() {
    if (!hasConsented()) { showConsentBanner(); return; }
    if (agentRunning) return;
    agentRunning = true;
    runHomePageFlow().finally(() => agentRunning = false);
  }
}

if (path.includes('services')) {
  // SERVICES PAGE
  if (path.includes('autostart=true')) {
    window.addEventListener('DOMContentLoaded', () => {
      setTimeout(() => {
        if (!agentRunning) {
          agentRunning = true;
          runServicesPageFlow().finally(() => agentRunning = false);
        }
      }, 800);
    });
  } else {
    document.getElementById('mic-btn')
      .addEventListener('click', handleMicClick);
  }
}

if (path.includes('apply')) {
  // APPLY PAGE
  window.addEventListener('DOMContentLoaded', () => {
    if (sessionStorage.getItem('agent_active') === 'true'
        && sessionStorage.getItem('agent_stage') === 'apply_form') {
      sessionStorage.removeItem('agent_stage');
      setTimeout(() => {
        agentRunning = true;
        runApplyFormFlow().finally(() => agentRunning = false);
      }, 900);
    } else {
      // Manual trigger via mic button on apply page
      document.getElementById('mic-btn')
        ?.addEventListener('click', handleMicClick);
    }
  });
}

## State handoff between pages (sessionStorage)

Before navigating from services.html to apply.html, set:
  sessionStorage.setItem('agent_active', 'true')
  sessionStorage.setItem('agent_stage', 'apply_form')

This tells apply.html to auto-continue the flow.
The mic button on apply.html also works as a manual trigger 
in case the user lands there directly.

Before navigating from index.html to services.html, the URL 
param ?autostart=true carries the signal instead of sessionStorage,
because the navigation is a link click not a JS redirect.

  function findField(strategies) {
    for (const selector of strategies) {
      const el = document.querySelector(selector);
      if (el) return el;

    return null;
