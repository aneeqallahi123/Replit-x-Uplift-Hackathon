# Dastak Voice Agent — Track B Build Instructions

## Context
This is a hackathon project. We are building a voice-first agent that 
helps Pakistani citizens renew their driving license on Punjab's Dastak 
portal by speaking Urdu. The agent visually operates the form on their 
behalf — the citizen never types anything.

This prompt covers Track B only: the UI layer, animated pointer, mic 
button, demo flow, and any backend needed to support it. Track A (real 
Urdu STT, field extraction via LLM, and TTS read-back via Uplift AI) is 
being built separately and will plug in later at clearly marked stub 
points. Do not attempt to build Track A. Do not call any Uplift AI 
endpoints yet. Just leave clean, well-commented stub functions for them.

### Section 3 — Core utility functions

delay(ms):
  Returns a Promise that resolves after ms milliseconds.

setStatus(text, show = true):
  Sets #mic-status-bubble textContent to text.
  Sets display to 'block' if show is true, 'none' if false.

movePointerToElement(el):
  Gets el.getBoundingClientRect().
  Sets #agent-pointer left and top to center on the element
  (subtract 22px from each — half of 44px pointer size).
  Adds .active class to show the pointer.
  Returns a Promise that resolves after 500ms 
  (time for CSS transition to complete).

fillField(fieldId, value):
  Gets the element by ID.
  Adds .field-highlight class.
  Clears the field value.
  Loops through each character of value:
    - Appends character to field.value
    - Dispatches new Event('input', { bubbles: true })
    - Awaits delay(60)
  After loop: awaits delay(300).
  Removes .field-highlight class.

triggerPulse():
  Removes .pulse from #agent-pointer.
  Forces reflow (void pointer.offsetWidth).
  Adds .pulse back.

### Section 7 — Main demo flow function (runDemoFlow)

async function runDemoFlow():

  Step 1 — Open the offcanvas:
    setStatus('لائسنس رینیوول سروس کھل رہی ہے...')
    querySelector('[data-service-key="renewal_driving_license"]').click()
    await delay(800)

  Step 2 — Loop through DEMO_SEQUENCE:
    For each step:
      const fieldConfig = FIELD_MAP[step.field]
      const el = document.getElementById(fieldConfig.id)
      setStatus(step.statusFill)
      await movePointerToElement(el)
      triggerPulse()
      await delay(200)
      await fillField(fieldConfig.id, step.value)
      await speakConfirmation(step.confirmation)
      // speakConfirmation is currently a stub — shows text + 1200ms wait
      // Track A will replace it with real Uplift AI TTS audio

  Step 3 — Advance through wizard steps:
    setStatus('اگلا مرحلہ...')
    pointer.classList.remove('active')
    await delay(400)
    document.getElementById('btn-next').click()   // Step 1 → Step 2
    await delay(600)
    document.getElementById('btn-next').click()   // Step 2 → Step 3
    await delay(600)
    document.getElementById('wizardTerms').checked = true
    await delay(300)
    document.getElementById('btn-next').click()   // Submit → success modal

  Step 4 — Finish:
    await delay(500)
    setStatus('فارم جمع ہو گیا ✅')
    await delay(2000)
    setStatus('', false)

## Definition of done for Track B

The following must work before Track B is considered complete:

1. services.html loads in browser — green mic button visible bottom-right
2. Click mic button — "Renewal of Regular License" offcanvas opens 
   automatically
3. Animated green pointer flies to Full Name field
4. Full Name fills character by character with typewriter effect
5. Status bubble shows Urdu confirmation text
6. Pointer flies to CNIC field
7. CNIC fills character by character
8. Status bubble confirms again
9. Wizard auto-advances through all three steps
10. Success modal fires
11. Entire flow runs in ~15 seconds without any keyboard input

Track A is not required for any of the above. The three stub functions 
(captureAndTranscribe, extractField, speakConfirmation) must exist in 
the file but do nothing meaningful yet. Their contracts are fixed — 
Track A will replace the internals without changing the function 
signatures.
