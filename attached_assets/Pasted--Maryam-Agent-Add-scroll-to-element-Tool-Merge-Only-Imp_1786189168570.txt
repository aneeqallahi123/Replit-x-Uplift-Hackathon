## Addition 1 — scrollToElement() helper function

Add this function alongside the existing helper functions 
(near waitForElement, delay, setStatus):

  // Smoothly scrolls an element into view WITHOUT waiting
  // for a click — used for orientation before navigation.
  // Maryam calls this to say "let me show you this section"
  // without requiring the citizen to click anything.
  function scrollToElement(selector) {
    return waitForElement(selector).then((el) => {
      el.scrollIntoView({ behavior: 'smooth', block: 'center' });
      return new Promise((resolve) => {
        setTimeout(
          () => resolve({ scrolled: true, element_id: selector }),
          700
        );
      });
    });
  }

## Addition 2 — handleScrollToElement() tool handler

Add this alongside handleGetPageContext, handleNavigateToPage, 
handlePointToElement, handleFillField, handleStartService:

  async function handleScrollToElement(payload) {
    console.log('[Maryam] scroll_to_element:', payload.element_id);
    showToolBadge('📜 ' + payload.element_id);
    try {
      const result = await scrollToElement(payload.element_id);
      return JSON.stringify({
        ...result,
        presentationInstructions:
          'Section scroll ho gayi. Aap dekh sakte hain.'
      });
    } catch (err) {
      console.error('[Maryam] scroll_to_element failed:', err.message);
      return JSON.stringify({ scrolled: false, error: err.message });
    }
  }

## What scroll_to_element enables

This tool fills the gap between arriving on a page and 
knowing where to click. Before this, Maryam could only 
navigate or point. Now she can:

1. User lands on homepage
2. Maryam says "Aapko DLIMS services chahiye? 
   Pehle dekh lete hain"
3. Maryam calls scroll_to_element("#govt_services")
4. Page scrolls smoothly to the services grid
5. Citizen sees the services section
6. Maryam says "Yeh hain available services. 
   Driving license ke liye aage chaltay hain"
7. Maryam calls navigate_to_page("services")
8. Browser navigates to services.html

The scroll gives the citizen visual context and 
orientation before navigation happens — it makes 
the experience feel guided rather than abrupt.
