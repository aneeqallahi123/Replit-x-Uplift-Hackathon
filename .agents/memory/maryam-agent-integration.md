---
name: Maryam agent integration gotchas
description: Non-obvious constraints in the Dastak Maryam voice agent (Uplift AI + LiveKit) integration
---

- `assets/js/maryam-agent.js` is the ONLY agent file; `voice-agent.js` was deleted (Aug 2026). Never reintroduce it or its `#agent-pointer`/`#voice-agent-panel` divs.
- On services.html the class names are swapped vs. meaning: `.apply_online` = **Self Service**, `.apply_self` = **Doorstep Service**. Keep the CAUTION notes in SITE_CONFIG.
- Uplift RPC payloads come in four shapes. ALWAYS go through `extractArgs()` — never inline `payload.arguments.raw_arguments`, which is `undefined` on the flat-`arguments` shape. `raw_arguments` may be a JSON *string*. Every RPC handler destructures inside its try block and every registration is wrapped so a bad payload returns `{error, presentationInstructions}` instead of rejecting — a rejected RPC gives the agent a hard tool error with no recovery text, which is indistinguishable from the agent going silent.
- `createPublicSession` needs no API key from the browser; `UPLIFT_API_KEY` is server-side-only (assistant config). `UPLIFT_BASE` is env-driven in both `server.js` and `scripts/sync-assistant.js`, defaulting to US; Singapore (`ap-southeast-1`) is lower latency from Pakistan but the assistant ID is NOT verified to resolve there.
- **Guided-flow RPCs are SEMI-BLOCKING** (this reverses the earlier "must be strictly non-blocking" note). One engine, `pointAndAwaitClick`, handles every pointing step: generation token, `activePointCancel`, scroll/resize repositioning, MutationObserver removal watcher, full cleanup on every exit path, and `onClicked()` run synchronously before resolve so flow state is persisted before navigation unloads the page.
  - Non-navigating steps (`select_card`, `select_mode`, `captcha`, `submit`) await it and return `clicked` / `still_waiting` / `captcha_correct` **in the tool result**. Why: whether the remote Uplift worker ingests `sendText(..., {topic:'lk.chat'})` as a user turn is UNVERIFIED. If it does not, a non-blocking point has no completion signal at all and the agent points once and goes silent forever. The tool result must carry the outcome. `[CLICK: …]` messages are kept as a redundant secondary signal — harmless if unread.
  - Navigating steps (`open_services`, `apply`) still return immediately: the page unload destroys the RPC response regardless. They rely on the next page's `pushPageContext`.
  - On timeout the listeners stay attached and the dot stays on screen, so a late click still counts.
  - Browser waits (20 s pointing, 30 s captcha) must stay under the remote tool timeouts (30 s) set by `sync-assistant.js`.
- **Captcha gotcha:** the citizen clicks the box and *then* types. A click listener fires immediately (nothing typed yet, reports "wrong"), and once they are focused in the box no second click ever arrives — permanent deadlock. Watch the input's `input` event and only report once `getCaptchaState().correct` is true. Never speak the answer aloud.
- **Select gotcha:** a `<select>` whose first `<option>` is a real value is never "empty", so the form step's missing-fields check silently skips it and the agent never asks. `fDuration` and `fPossession` in `apply.js` need their `<option value="">Select…</option>` placeholder — and `validateLicenseLookup()` must reject the empty case (guarded on element presence: `duplicate-license` reuses that validator without those fields).
- **Never resume a saved session token across pages.** The Uplift agent worker ends its session when the only human participant disconnects, so a resumed token lands you in a room with no agent: mic live, UI green, nothing responds. Same identity also races the old connection's teardown. `getOrResumeSession()` always calls `createNewSession()`. `agentNavigated` survives only as the auto-reconnect hint, and must be read BEFORE `createNewSession()` overwrites the stored session.
- Advances go through `advanceFlow()`, which stamps `flow.lastAdvancedAt`; `executeCurrentFlowStep` returns `debounced: true` if re-entered within 500 ms (internal recursion passes `skipDebounce`). A navigating step emits both `[CLICK]` and `[PAGE UPDATE]` and they can arrive out of order. `loadFlow()` discards flows older than 30 min.
- Remote Uplift assistant config is editable via API (GET, and POST to the same resource for updates — PATCH/PUT 404). Browser-registered RPC tools are invisible to the agent unless also declared in the assistant's tool list. Sync via `scripts/sync-assistant.js` (idempotent, `--dry-run`, anchor mismatches warn rather than exit).
- `[CLICK]` notifications for navigating steps are stored in `sessionStorage('maryam_pending_click')` and replayed by pushPageContext after reconnect — the WebSocket is torn down before sendText() can flush on native link navigation.
- Audio autoplay is blocked after navigation (no user gesture on the new document — the previous page's gesture does not carry over). `attachAudioTrack` registers retry handlers for click/touchstart/keydown, shows an Urdu tap prompt via `setStatus` immediately, a "Tap to hear" badge after 3 s, and calls `window._maryamRetryAudio` on ActiveSpeakersChanged (user speaking = in-tab gesture context). Silence with no explanation reads exactly like the agent having died.
- Auto-reconnect fires whenever a saved session exists, not only after an agent-driven navigation — otherwise any ordinary link click kills Maryam with no indication.
- `pushPageContext` waits for `RoomEvent.ParticipantConnected` (5 s fallback) before pushing, and retries once after 2 s if `remoteParticipants.size === 0`. A fixed delay lost the `[PAGE UPDATE — ACTION REQUIRED]` message whenever the agent joined late.
- Pointer animation is never awaited (`movePointerTo` is fire-and-forget) — the dot moves while Maryam talks. Awaiting it cost >1 s per action and read as a broken agent.
- `window.__maryam` is the console debug handle (room, connected, flow helpers, `executeCurrentFlowStep`, `getCaptchaState`, `buildLiveContext`, `FLOW_STEPS`).
- GitHub origin diverges easily (team pushes via web upload); expect PUSH_REJECTED → merge origin/main keeping local agent files.
